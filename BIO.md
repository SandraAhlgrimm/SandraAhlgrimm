Sandra Ahlgrimm is a Senior Developer Advocate at GitHub/Microsoft, specializing in supporting Java developers. With more than a decade of experience as a Java developer, she brings practical engineering expertise to her advocacy work. Sandra leads Developer Experience for GitHub Copilot integrations in JetBrains IDEs, helping developers make the most of AI-assisted development in the tools they use every day.

Sandra is passionate about Java, containers, cloud technologies, and AI. She leads the Berlin Java User Group (JUG) and the Berlin Docker Meetup, and is committed to fostering collaboration across the developer community. Sandra represents GitHub/Microsoft on the GraalVM Program Advisory Board and in the Java Community Process (JCP), helping bring developer perspectives to the evolution of the Java ecosystem.
