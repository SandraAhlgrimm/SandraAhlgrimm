Sandra Ahlgrimm is a Senior Developer Advocate on GitHub's Enterprise team. With more than a decade of experience as a Java developer, she brings practical engineering expertise to her advocacy work.

Sandra is passionate about Java, containers, cloud technologies, and AI, and about fostering collaboration across developer communities. She leads the [Berlin Java User Group (JUG)](https://www.jug-berlin.de/) and the [Berlin Docker Meetup](https://www.meetup.com/docker-berlin/). Sandra also represents GitHub on the GraalVM Program Advisory Board and in the Java Community Process (JCP), bringing developer perspectives to the evolution of the Java ecosystem.
